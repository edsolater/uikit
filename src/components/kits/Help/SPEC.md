# Help

Help 是简短补充说明的独立入口，默认呈现圆圈问号。字段外的说明可以直接使用 Help；Label 的 `tooltip` 属性只是将它放到标题末尾的快捷方式。

- `tooltip` 接受字符串、JSX 模板及其 Source；空值和空字符串不显示浮层，入口仍存在。Help 声明即显示，是否组合它由调用方决定；Label 在说明非空时才组合 Help。内容用于补充说明，不代替正文。
- `trigger` 只替换问号内的显示内容，不放入另一个交互控件；未提供时显示问号。`name` 是可访问名称，缺省为“帮助说明”。
- 问号固定为 `type="button"`，不提交表单。悬停、焦点、移入浮层继续阅读与 Escape 退出复用既有 `tooltip` 插件；tooltip 内部复用 createPopoverPlugins 的定位与显隐，实际单 Piv 正文承载提示材料，不另造背板。
- Help 拥有入口 DOM、圆圈样式及 kit 透明身份，不复制浮层引擎，也不解释业务文案。内容清空时关闭并移除附属浮层、清理关闭计时；同一能力再次有内容时复用其正文节点，实例销毁时释放入口及浮层。
- 初始内容通过 Props 表达；可选 `HelpController.props` 支持运行期更新，未接入 ref 的实例不进入受控集合。
