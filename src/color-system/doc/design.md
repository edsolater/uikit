# 职责

- Color System：颜色信息与 JS 计算，内部采用 OKLCH。
- Style System：JSS 与 CSS 表达；具体色板留在 Pieces。

# 颜色与原色

程序中统一都是颜色。原色是业务对一类颜色的称呼：没有透明度、没有经过任何颜色处理、没有叠加环境效果。

原色本身也是颜色；处理或加入环境后仍是颜色，只是不再属于原色分类。原色不绑定 Purpose 或 Level，不需要独立的一套程序对象。

# 用途、风格与状态

| 概念 | 描述对象 | 例子 |
| --- | --- | --- |
| 用途（Purpose） | 颜色承担的角色，可按 Level 分类 | Content、Surface |
| 层级（Level） | Purpose 的一个分类维度 | Content 为 0，Surface 可为 -1、-2 |
| 色调风格（Flavor） | 色彩的呈现风格，不改变所处层级 | 柔和、鲜明 |
| 状态（State） | 激活等状态，与 Flavor 分开 | 激活、禁用 |

柔和的品牌色仍可用于 Content。同一 Level 可以包含不同 Purpose；Level 不决定颜色是否经过处理。

# 颜色处理

- 工具位于 `src/color-system/tools/`；`channels.ts` 导出四个通道函数，`emphasis.ts`、`mix.ts` 分别导出同名函数。
- `lightness`、`chroma`、`hue`、`alpha` 接受数值或更新函数：数值设置绝对值，函数以当前值计算新值。
- `base` 只含 OKLCH；可选 `alpha` 单独存放，省略等效于 1。`alpha(color, 1)` 移除属性。
- `emphasis(color, environment, level)` 表达近处清晰、远处褪色；0 原样返回。整数展示色阶，小数供连续过渡；处理级数不是 Purpose 的分类 Level。
- 强调实际改变自身 `base`，同时调整后续环境感知；动态规则继续读取处理后的自身色值。传入环境只作参照，不追加贡献，Alpha 与用途不变。
- `emphasis` 的入口直接呈现目标、平滑过渡与感知调整；只计算 OKLCH 颜色信息，显示色域转换与映射由显示层负责。
- `mix` 支持多份材料直接传入，或用配置对象指定颜色、权重与色相路径；Alpha 混合采用预乘规则。
- 处理函数接收颜色、返回颜色；原色与处理过的颜色共用这些函数。
- 处理可以改变明度、彩度、透明度及环境感知，不自动改变 Purpose 的 Level。
- 原 `atLevel` 已移除；Purpose 的 Level 不再作为颜色处理入口。

# 视觉验收

颜色函数是否好用，必须让用户看到实际效果；数值测试不能代替人眼判断。

- 测试与修改颜色函数时，交付可直接查看的色块图或色阶图；直接调用被测实现，不另写演示算法。
- 每行固定输入颜色与环境，只改变被测参数；标出原色、环境色和参数值，以环境色作底。
- 覆盖多种颜色及亮、暗环境；涉及冷暖时加入冷暖环境，涉及 Alpha 时展示实际背景上的效果。
- `emphasis` 默认从左到右展示 `+2、+1、0、−1、−2`，0 级与原色并列可比；这五级是展示样例，不限制函数范围。
- 同时展示密集取样的连续色带与颜色变化率曲线；检查穿过 0 级及其他位置时是否突然换挡。连续颜色坐标中至少一阶导数连续，色相回绕与无彩点不作为可见跳变。
- 图片用于判断突出、融入、通透、发灰或偏色等视觉效果；数值测试另行验证计算与边界。测试通过不代表视觉效果已获认可。

# 材料与环境

- 颜料：基色 + 环境感知指数 + 用途（surface / content）。
- 感知指数属于材料，表达材料受环境影响的程度；环境参数表达外部条件。
- 材料只用 `environmentSensitivities` 保存环境感知规则，明度、彩度、色相分别配置；省略按 0 处理。
- 每项可以是固定比例，或 `(base, environment) => 比例`。`base` 指材料自身当前 OKLCH，`environment` 指合成环境；函数结果须在 0～1。
- 任何通道都可根据自身色相等信息改变响应，不能把感知限定成固定数值。
- 感知决定接受多少影响，环境作用公式决定变化方向与幅度；材料不再保存环境偏移量。
- 加入环境后仍是一份颜色，自身 base 更新为受影响后的色值，保留材料感知，可继续应用其他环境；不保存环境历史。
- 多环境与权重只作为本次 applyEnvironment 的参数；按本次权重合成后作用，不保存贡献或累计权重。
- 已取消相同环境不变的要求；再次应用从当前 base 计算，按普通环境作用处理。

当前求值向环境 `tint` 靠近，外部 `influence` 决定作用强度。原固定亮暗偏移已移除；按用途决定暗模式明暗目标的公式尚未确定，不能声称当前公式可自动将黑字变为白字。

# 处理的变化率

以下是褪色与环境感知处理的自然参考，不是 Level 的分类规则。

- 自然依据：均匀介质、环境光稳定时，自身与环境的光强差异随距离指数衰减。
- 等距离增加，每段削弱剩余差异的相同比例；绝对变化量先大后小，逐渐趋近环境。
- 例如差异 `100 → 50 → 25`，两段变化量是 `50、25`；比例仅作示意。
- UI 借用这种先快后慢的趋势，不把物理光强公式直接套到 OKLCH，也不把层级当米数。

现役 `emphasis` 采用平缓起步、加速后减速的曲线，让 0 两侧平滑衔接；上述指数衰减是自然参考，不是必须从 0 立即开始减速的 UI 规则。

自然依据：[Depth from Scattering](https://www.cs.cmu.edu/~viper/Papers/CVPR97/CVPR97.html)。
