# 环境叠加公式

多环境仅在本次应用时参与权重计算。颜色材料不保存环境列表、累计权重或曾受影响的标记。

## 本次权重

对实际提供某通道的环境，按相对权重合成：

```text
合成环境目标 = Σ(权重 × 环境通道) / Σ权重
本次响应目标 = 材料明度目标（仅明度可选）或合成环境目标
新通道 = 当前通道 + (本次响应目标 - 当前通道) × 外部影响 × 材料感知
```

- 直接传入环境，权重为 1；显式权重须非负且有限，至少一项大于 0。
- 缺省通道不参与该通道的合成；零权重不参与。
- 色相沿最短圆周路径混合，多环境的色相可能受输入顺序影响。
- 材料的动态感知读取本次输入的 base 与合成环境，不提前固定。
- 材料明度目标同样读取合成环境；未提供环境明度时不求目标，也不改明度。

## 调用与结果

```ts
const changed = applyEnvironment(color,
  { environment: dark, weight: 3 },
  { environment: warm, weight: 1 },
)
const changedAgain = applyEnvironment(changed, anotherEnvironment)
```

结果仍是 ColorMaterial：base 已改变，Alpha、用途和环境感知保留；可继续混合、处理通道或应用环境。输入材料不变。

## 再次应用

再次应用只读取当前 base 与本次环境，不沿用上次环境，不判断身份或去重。

例如明度为 0.6、感知为 0.5，连续两次应用明度 0.2 的环境：`0.6 → 0.4 → 0.3`。

此前“相同环境自然不变”与累计保存环境贡献的约定已取消。
