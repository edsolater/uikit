# 怎样使用主体状态

需要同一材料在hover、active等主体状态下反馈时，把状态写在Variable中，再交给效果API消费。本页解释用法；根据地主体、名称、次序及禁用边界见[states与条件选择.md](behaviors/states与条件选择.md)。

## 名称与顺序

内置hover、active、focus等可以直接用于states。多个材料确实需要共用自定义名称时，再用stateCondition(name, condition)登记；只有一次用途也可以直接写条件。名字是否合法、直接条件与普通Rules字符串的区别见[states与条件选择.md](behaviors/states与条件选择.md)。

需要焦点提示时，本例使用focus快捷项；它与focusVisible、原生whenFocus各有什么含义，见[states与条件选择.md](behaviors/states与条件选择.md)。这不是让鼠标取得焦点就必定绘制轮廓。

## Variable自己提供反馈

```ts
const feedbackColor = variable('red', {
  name: 'feedback-color', address: '.Feedback',
  states: { hover: 'pink', active: 'darkred' },
})
rules('.Feedback', [[key('color'), feedbackColor]])
```

本例元素普通为红色、悬停粉红、按下深红。使用处仍消费feedbackColor；多个状态同时成立及禁用时，按[states与条件选择.md](behaviors/states与条件选择.md)得到结果，不以生成声明条数解释效果。

```text
一个新材料需要复用反馈：在它的Variable中选择states
状态随根据地：组件状态模板须给Variable指定组件address；也可在hover/active条件rules中modify表达变化
需要位置或屏幕条件：在Rules中选择普通Condition
```

## 派生定义复用状态

另一个材料要沿用已有默认与反馈时，用variableFrom(source, value, nameOrOptions)表达差异；完整API及创建时复用见[Variable的创建与复用.md](behaviors/Variable的创建与复用.md#从已有定义复用规则)，可照用例子见[Variable教程](变量定义与消费.md#用-variablefrom-复用复杂状态和变体)。

## 组合普通内容

混色或Value包装可以使用feedbackColor，再由浏览器取得当前颜色。组合遵循[CSS作用域与层叠.md](behaviors/CSS作用域与层叠.md)，不会把来源状态复制到包装，也不会因子元素同名输入而搬运祖先公式；维护状态路径和选择器权重实现时再读[架构](../architecture.md#状态与变量接入)。
