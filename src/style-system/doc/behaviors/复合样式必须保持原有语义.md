# 目的

混色、字体和计算值经过 Style System 后仍须表达调用者指定的 CSS 含义。组成项、比例和单位不能在通用编译过程中丢失或被误读。

# 典型案例

```ts
const css = compileRules([
  [[condition('.Probe')], 'background-color', colorMix(['black', 0.5], 'white')],
  [[condition('.Probe')], 'font', fontValue({
    style: 'italic', size: '16px', lineHeight: 1.5, family: 'system-ui',
  })],
  [[condition('.Probe')], 'width', calcMultiply('12px', 2)],
])
expect(css).toContain('background-color: color-mix(in oklab, black 50%, white);')
expect(css).toContain('font: italic 16px/1.5 system-ui;')
expect(css).toContain('width: calc(12px * 2);')
```

# 反例

若比例没有转为 `50%`、字体斜杠位置错误、乘法运算符丢失，或组成项被丢失，断言失败。
