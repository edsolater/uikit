# 目的

混色、字体和计算值经过 Style System 后仍须表达调用者指定的 CSS 含义。组成项、比例和单位不能在通用编译过程中丢失或被误读。

# 典型案例

```ts
const css = compileRules([
  [[condition('.Probe')], 'background-color', colorMix(['black', 0.5], 'white')],
  [[condition('.Probe')], 'font', fontValue({
    style: 'italic', size: '16px', lineHeight: 1.5, family: 'system-ui',
  })],
  [[condition('.Probe')], 'width', multiply('12px', 2)],
])
expect(css).toContain('background-color: color-mix(in oklab, black 50%, white);')
expect(css).toContain('font: italic 16px/1.5 system-ui;')
expect(css).toContain('width: calc(12px * 2);')
```

## 具名函数与动画内容案例

行为伪代码，不能直接运行：用cssFunction定义接收size/inset的具名函数，函数体result为`calc(var(--size) - var(--inset) * 2)`；将调用100px/8px用于width，构建应提供对应@function和调用表达式，支持该CSS语法的浏览器计算为84px。调用返回Expression；定义按需及同名完整性由[资源行为](未使用的资源不进入样式结果.md)、[同名定义](同名样式定义必须完整一致.md)负责，不承诺所有浏览器均支持该语法。

另用animationName(name, frames)保存from opacity0/to opacity1，animationValue({name, duration:'1s', easing:'linear', fillMode:'forwards'})组合用于元素。实际播放1秒结束为1，支持并正常播放时0.5秒为0.5；系统不凭空添加未配置的减少动效分支。清理时撤销两例消费及DOM/style，无其他需求则不保留独有函数和关键帧。

# 反例

若比例没有转为 `50%`、字体斜杠位置错误、乘法运算符丢失，或组成项被丢失，断言失败。
