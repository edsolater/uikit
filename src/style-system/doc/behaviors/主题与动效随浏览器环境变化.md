# 目的

主题和减少动效是运行环境的变化，样式应随浏览器当前条件取得对应值。生成样式时不能把某个主题提前选成唯一结果；未配置的分支也不应凭空出现。

# 典型案例

```ts
const baseline = compileCSS()
const size = variable('4px', {
  name: 'theme-size',
  root: { value: '8px', dark: '12px', reducedMotion: '0px' },
})
expect(compileRules([])).toBe('')
expect(compileCSS()).toBe(baseline)

const css = compileRules([[[condition('.Probe')], 'width', size]])
expect(css).toContain('width: var(--theme-size, 4px);')
expect(css).toMatch(/:where\(:root\)\s*\{\s*--theme-size:\s*8px;/)
expect(css).toMatch(/&:where\(\[data-theme="dark"\]\)\s*\{\s*--theme-size:\s*12px;/)
expect(css).toContain('@media (prefers-reduced-motion: reduce)')
expect(css).toContain('--theme-size: 0px;')

const plain = variable('4px', {
  name: 'plain-size', root: { value: '8px' },
})
const plainCSS = compileRules([[[condition('.Plain')], 'width', plain]])
expect(plainCSS).not.toContain('data-theme')
expect(plainCSS).not.toContain('prefers-reduced-motion')
```

# 反例

若未消费时就输出根配方、使用后漏掉任一显式分支，或将主题选择提前固定为某一个值，断言失败。CSS 地址正确不等于浏览器主题切换已验证。
