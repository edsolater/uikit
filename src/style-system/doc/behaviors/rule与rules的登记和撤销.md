本文按 Token 模型描述登记行为，源码已完成 Token 迁移；不涉及 Token 的登记与撤销原则继续保留。

样式由条件、目标和内容共同表达。登记将它们作为一份有归属的贡献加入系统；复用和撤销以贡献归属为界，不能只按最终文本识别谁拥有样式。

# 明确作用范围，保留书写顺序

```ts
const width = rule('.Probe', 'width', '12px')
width.replace('20px')
const text = rule('.Probe', 'color', 'red')
width.remove()
```

第一次编译 Probe 宽 12px，替换后为 20px；撤销 width 后不再提供该宽度贡献，text 的红色仍保留。重复撤销无额外效果，已撤销贡献不能再被替换或在下一次编译复活。页面何时更新由 [Compile与挂载.md](Compile与挂载.md) 决定。

即使两次登记的条件、目标、内容完全相同，它们仍属于不同来源。撤销第一个，不撤销第二个。批量 rules 返回的归属覆盖自己的一整批；中途无效或输入迭代失败时，不能遗留前半批，也不能伤害此前成功登记。

Key 表示普通 CSS 属性，Token 正常作为内容引用并按自身 address 自动定义。Mixin 将一组业务效果作为一次选择，只提供明确选择的效果：仅要求 gap 时，不能附赠 display 或 alignment。固定属性内容可以直接书写，不要求额外创建命名对象。

# 多种输入统一展开为声明

rules 的第二参数可以是一个 `[目标, 内容]`、普通对象，或递归嵌套的数组及标准 Iterable。普通对象按自身可枚举字符串属性展开；二元组保留 Key／Token 目标对象及内容，不先做 JS 字符串化。

```ts
const ink = token('black', { name: 'probe-ink', address: '.Probe' })
const batch = rules('.Probe', [
  { padding: '2px', color: ink },
  ['border-color', ink],
  new Set([['border-width', '1px'] as const]),
])
```

每个属性 entry 由 rules 自动完成声明，Token 的默认及状态声明由编译器按自身定义建立；上例不需要再为 ink 手写 declare。Key 的组合规则和 Token 的根据地、状态及资源身份都保留。字符串名称沿用既有 CSS 属性、已登记别名及自定义属性解析，不从未知简写推测属性含义。

集合里的裸 undefined 作为空项跳过，普通属性 undefined 不输出。modify 及 Mixin 返回的条目可以继续混用，归一后不产生第二层普通基础包装。

# 危险的手动声明仍可使用

手动 declare 及以已有 Token 为目标的 [token, value]、[token, undefined] 保留原能力；这是君子协定，不加运行时拒绝、警告或类型禁用。正常定义使用 Token 自身 default、state、address，独立配置则创建新 Token 并接入属性消费。

主动使用危险入口时，[ink, undefined] 仍等价于 declare(ink, undefined)，保留显式无基础声明；调用方承担它影响状态基础、其他引用及 CSS 层叠的后果。下面的 Token 重声明顺序描述的是这条低层能力，不是推荐的业务模板。

展开保持顺序；entry 的内容不会被误拆成外层声明集合。非法项、递归容器或迭代中断在整批登记前失败，batch.remove() 仍只撤销本批贡献。

# 同址选择与跨地址层叠分开

同一完整地址、同一 Token 目标的有效贡献按声明顺序处理；Token 不保存 priority。未定义内容不输出 CSS 值，但“不输出”与“不登记”不同：Token 的 undefined entry 仍保留前述显式声明身份。不同地址仍交给 CSS 层叠，内部处理不能跨选择器替代浏览器决定最终结果。

同址有效赋值依次为 4、7、9 时，取 9；撤销 9 后取 7。集合空项和普通属性 undefined 不增加输出；Token 的显式 undefined 不输出新值，也不强制清除此前有效的 CSS 贡献，但会阻止根据地缺值时自动补回 default。其他选择器下的赋值需要按 CSS 特异度和源序判断，不能照搬同址结果。

普通 Key 可约定组合多份贡献。组合保留同完整地址内参与贡献的源序，不把其他条件的内容混入。例如阴影 A、B 按逗号组合；撤销 B 后只留下 A，而不是清空整组。关键字 none 不自动成为“删除其他贡献”的编译命令。

组合须保留各项原内容的含义及求值位置，不能为拼接额外执行业务生产函数。互相冲突的组合约定明确失败，不交付半份结果。登记接口见 [接口协议](../当前接口与扩展协议.md)。

登记控制的是自己的贡献；一项内容带入的共享资源还须遵循 [按需资源与同名替换.md](按需资源与同名替换.md)。这是同一归属原则在直接样式和依赖资源上的组合。
