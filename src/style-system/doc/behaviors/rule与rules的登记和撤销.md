本文按 Token 模型描述登记行为，源码已完成 Token 迁移；不涉及 Token 的登记与撤销原则继续保留。

样式由条件、目标和内容共同表达。登记将它们作为一份有归属的贡献加入系统；复用和撤销以贡献归属为界，不能只按最终文本识别谁拥有样式。

# 明确作用范围，保留书写顺序

```ts
const width = rule('.Probe', 'width', '12px')
width.replace('20px')
const text = rule('.Probe', 'color', 'red')
width.remove()
```

第一次编译 Probe 宽 12px，替换后为 20px；撤销 width 后不再提供该宽度贡献，text 的红色仍保留。重复撤销无额外效果，已撤销贡献不能再被替换或在下一次编译复活。页面何时更新由 [Compile与挂载.md](Compile与挂载.md) 决定。

即使两次登记的条件、目标、内容完全相同，它们仍属于不同来源。撤销第一个，不撤销第二个。批量 rules 返回的归属覆盖自己的一整批；中途无效或输入迭代失败时，不能遗留前半批，也不能伤害此前成功登记。

Key 表示普通 CSS 属性；具有 CSS variable 身份的 Token 可作为自定义属性赋值目标，Token 也可作为内容引用。Mixin 将一组业务效果作为一次选择，只提供明确选择的效果：仅要求 gap 时，不能附赠 display 或 alignment。固定属性内容可以直接书写，不要求额外创建命名对象。

# 同址选择与跨地址层叠分开

同一完整地址、同一 Token 目标的有效贡献按声明顺序处理；Token 不保存 priority。undefined 不能压过有效值。不同地址仍交给 CSS 层叠，内部处理不能跨选择器替代浏览器决定最终结果。

同址有效赋值依次为 4、7、9 时，取 9；撤销 9 后取 7；加入 undefined 仍取 7。其他选择器下的赋值需要按 CSS 特异度和源序判断，不能照搬同址结果。

普通 Key 可约定组合多份贡献。组合保留同完整地址内参与贡献的源序，不把其他条件的内容混入。例如阴影 A、B 按逗号组合；撤销 B 后只留下 A，而不是清空整组。关键字 none 不自动成为“删除其他贡献”的编译命令。

组合须保留各项原内容的含义及求值位置，不能为拼接额外执行业务生产函数。互相冲突的组合约定明确失败，不交付半份结果。登记接口见 [接口协议](../当前接口与扩展协议.md)。

登记控制的是自己的贡献；一项内容带入的共享资源还须遵循 [按需资源与同名替换.md](按需资源与同名替换.md)。这是同一归属原则在直接样式和依赖资源上的组合。
