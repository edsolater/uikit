# 目的

变化自身可声明、共享和覆盖，组合结果保留来源与变化的独立控制关系。

# 典型案例

行为伪代码，不能直接运行：创建两种来源色、共享一个change并分别adjust，登记两结果后挂载；区域只改change时两结果均随动，只改其中source时另一结果不变。计算颜色须比较实际浏览器值，不能仅检查var名称。

`adjust(source, change)`返回新Variable。两个来源共享一个change时，当地改change应同时改变两者，当地只改一个source应只改变相应结果。颜色固定通道表示替换，回调通道表示相对当前值变化，未指定通道包括透明度应保持。

公开`modification({type: 'color', name?, detail})`返回独立可声明的Modification，显式name为完整CSS自定义属性名，省略生成匿名名称。detail保存颜色通道或通道回调；构造不执行回调，构建消费时回调收到相应通道表达式。配方与来源分离，不预先读取JS颜色通道数值；目前没有运行时安装策略或控制器自动重编译接口。Adjust接收公开来源/变化自然材料，不要求品牌或特定构造来源；其目标key及领域合法性由[声明材料](样式声明必须明确目标与内容.md)约束。

`declare(adjusted)`提供结果需要的缺失来源与变化；适用的显式来源/变化继续有效，不能强行回默认。按现役共同声明契约，`declare(adjusted, replacement)`替换结果内容时仍共同提供来源与变化，不能将替换当成取消这项声明用途。退出一个结果不误删另一个共享需求；最后需求退出才清理相应自动资源。

清理：先撤销一个结果确认另一结果与共享变化仍有效；再撤销最后结果并重编译核对独有资源退出，移除案例DOM/style。

# 反例

改变一个来源误改另一个结果、覆盖变化无效、丢失未指定透明度、替换结果取消共同声明用途或撤销一个结果误删共享需求，均违反目的。

# 推断依据

现役公开adjust及自然材料共同声明契约，用户要求保留用途。[调整共同声明测试](../../test/调整绑定共同声明并保留内容引用.test.ts)为核对证据。尺寸Modification尚未定义；控制器修改参数、通知及自动重编译仍是后续能力，不新增运行时控制接口。
