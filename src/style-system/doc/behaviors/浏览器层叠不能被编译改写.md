# 目的

样式声明最终交给浏览器层叠。编译器可以改变内部表示和输出分组，但不能重排、合并或提前计算到让相同输入在浏览器得到不同结果。

# 典型案例

```ts
const source: Rules = [
  [[condition('.Probe'), condition('@media (min-width: 0px)')], 'padding', '1px'],
  [[condition('.Probe')], 'padding-left', '2px'],
  [[condition('.Probe'), condition('@media (min-width: 0px)')], 'padding', '3px'],
]
const css = compileRules(source)
const first = css.indexOf('padding: 1px;')
const middle = css.indexOf('padding-left: 2px;')
const last = css.indexOf('padding: 3px;')
expect(first).toBeGreaterThanOrEqual(0)
expect(middle).toBeGreaterThan(first)
expect(last).toBeGreaterThan(middle)
expect(css.match(/@media \(min-width: 0px\)/g)).toHaveLength(2)

const style = document.head.appendChild(document.createElement('style'))
style.textContent = css
const element = document.body.appendChild(document.createElement('div'))
element.className = 'Probe'
try {
  expect(getComputedStyle(element).paddingLeft).toBe('3px')
} finally {
  element.remove()
  style.remove()
}
```

媒体条件始终匹配，三条声明权重相同。若把第三条 `padding` 移到 `padding-left` 前面，最终左内边距会变为 `2px`。案例不固定换行和缩进。

无媒体条件的简写与详细属性同样需要保留浏览器看到的先后关系：

```ts
const css = compileRules([
  [[condition('.Probe')], 'padding', '2px 4px'],
  [[condition('.Probe')], 'padding-left', '8px'],
  [[condition('.Probe')], 'padding', '10px'],
])
expect([...css.matchAll(/(padding(?:-left)?):\s*([^;]+);/g)]
  .map(([, property, text]) => [property, text.trim()])).toEqual([
    ['padding', '2px 4px'], ['padding-left', '8px'], ['padding', '10px'],
  ])
```

# 反例

若移动第三条 `padding` 到第一条旁边、吞掉重复声明或提前合并两个媒体块，顺序或浏览器计算值断言失败。
