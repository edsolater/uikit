# 目的

多层条件用于逐步限定样式生效的范围。编译后仍须满足调用者写下的每一层限制，不能因条件文字相同就删除一层，也不能让内层声明逃到外层主体。

# 典型案例

```ts
const handle = rule(undefined, undefined, [
  [[condition('.Probe'), condition('&:hover')], 'color', [
    [[condition('&:hover')], undefined, 'blue'],
  ]],
])
try {
  expect(compileCSS()).toMatch(
    /\.Probe\s*\{\s*&:hover\s*\{\s*&:hover\s*\{\s*color:\s*blue;\s*\}\s*\}\s*\}/
  )
} finally {
  handle.remove()
}
```

`condition('&:hover')` 是显式普通地址，因此两层 hover 都须保留；不能因为文字相同就当作状态名称去重。

# 反例

若删除一层 hover、把嵌套的 `color` 丢失，或将普通条件改写为主体状态选择器，全文断言失败。
