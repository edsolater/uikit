# Token 与表达式

本文描述 Token 的契约，源码已完成 Token 迁移。Token 统一承载直接内容、引用、计算与可选状态，不再额外创建一类内容包装对象。完整创建接口见 [Token的创建与复用.md](Token的创建与复用.md)。

## 内容按其表达的含义组合

```ts
const spacing = token('2px')
const width = token(multiply(spacing, 2))
const surface = token(colorMix(['black', 0.5], 'white'))
```

这是现役写法。spacing 没有名称、状态、地址、注册或 modify 需求时直接输出 2px；width 的 default 是乘法表达式。表达式中的 Token 与其他可坍缩内容按同一方式消费，既不复制其定义，也不因为出现在不同位置就改变外界读取它的方式。

混色比例、单位、列表的逗号和空格含义不能被通用输出丢掉。合法 0 保留，空项不额外占据分隔位置。组合读取已经取得的子项结果，不为格式化再次执行业务生产函数。

## 表达式引用保留 CSS 含义

一个 Token 若需要 CSS variable 身份，表达式消费得到相应引用；否则得到直接 CSS value。身份由系统内部 _kind 决定，在相关修改读取完毕后才坍缩，不能在构造表达式时冻结输出形式。

表达式不复制来源的 JS state，不自动枚举多个来源的状态交集。浏览器按实际公式位置读取适用的 CSS 值；后代覆盖输入不使祖先公式重新求值，见 [CSS作用域与层叠.md](CSS作用域与层叠.md)。

CSS 函数与关键帧等资源仍按实际引用参与编译。引用是内容本身表达的关系，不需要 Token 额外保存共同声明列表或加工来源账本，资源生命周期见 [按需资源与同名替换.md](按需资源与同名替换.md)。

## 求值与失败

创建定义和登记使用不等于立即坍缩。编译只处理本次真正使用的内容；一次结果不能为探测关系而重复运行源函数、混用不同返回值。

这里要求的是同一次结果的一致性，不规定所有普通函数永久精确调用几次。组合失败明确报错，不能把函数源码作为 CSS 或吞掉异常。

同一 Token 在混色两端出现属于共享，应能正常完成；最终递归依赖自身则明确失败，不无限展开或交付部分 CSS。合法共享不能被误判为循环。这不要求编译器穷举浏览器中所有可能的 CSS 自定义属性环。
