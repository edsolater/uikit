# 目的

组件可以给共享样式角色赋局部值。该值应影响本组件及其后代，不改变角色本身，也不污染相邻组件；显式局部值不能被系统自动补出的缺省值盖掉。

# 典型案例

```ts
const color = variable('black', {
  name: 'local-color', states: { hover: 'gray' },
})
const assignment = rule('.Probe', color, 'red')
const consumer = rule('.Probe', 'color', color)
try {
  const css = compileCSS()
  expect(css).toContain('--local-color: red;')
  expect(css).toContain('color: var(--local-color, black);')
  expect(css).not.toContain('--local-color: black;')
} finally {
  assignment.remove()
  consumer.remove()
}
```

浏览器案例检查局部声明是否越过选择器边界：

```ts
const color = variable('black', { name: 'scope-color' })
const local = rule('.Local', color, 'red')
const localUse = rule('.Local', 'color', color)
const otherUse = rule('.Other', 'color', color)
const style = document.head.appendChild(document.createElement('style'))
style.id = 'css-root'
try {
  cssRoot.mount()
  const inside = document.body.appendChild(document.createElement('div'))
  inside.className = 'Local'
  const child = inside.appendChild(document.createElement('span'))
  child.className = 'Child'
  const outside = document.body.appendChild(document.createElement('div'))
  outside.className = 'Other'
  expect(getComputedStyle(inside).color).toBe('rgb(255, 0, 0)')
  expect(getComputedStyle(child).getPropertyValue('--scope-color').trim()).toBe('red')
  expect(getComputedStyle(outside).color).toBe('rgb(0, 0, 0)')
} finally {
  document.body.replaceChildren()
  local.remove()
  localUse.remove()
  otherUse.remove()
  style.remove()
}
```

# 反例

若自动缺省值压过显式值、局部值不能被后代继承，或相邻主体也变红，对应断言失败。
