# 目的

每次样式登记都应独立受控。替换或撤销自己的样式时，不能按选择器、属性或内容误伤别人的登记；撤销后的结果也不能继续留在后续编译中。

# 典型案例

```ts
const first = rule('.Probe', 'color', 'red')
const second = rule('.Probe', 'color', 'red')
try {
  first.replace('blue')
  expect([...compileCSS().matchAll(/color:\s*([^;]+);/g)]
    .map(([, text]) => text.trim())).toEqual(['blue', 'red'])

  first.remove()
  expect([...compileCSS().matchAll(/color:\s*([^;]+);/g)]
    .map(([, text]) => text.trim())).toEqual(['red'])
  expect(() => first.replace('green')).toThrow('已删除')
} finally {
  first.remove()
  second.remove()
}
```

批量登记也应只撤销自己的一批：

```ts
const batch = rules('.Probe', [[key('color'), 'red'], [key('padding'), '4px']])
const neighbor = rule('.Probe', 'color', 'blue')
try {
  batch.remove()
  const css = compileCSS()
  expect(css).toContain('color: blue;')
  expect(css).not.toContain('color: red;')
  expect(css).not.toContain('padding: 4px;')
} finally {
  batch.remove()
  neighbor.remove()
}
```

# 反例

若撤销一个来源时误删同地址的其他来源、只删除批量登记的一部分，或让已撤销来源重新生效，案例会失败。
