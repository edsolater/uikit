# 目的

同一个样式变量可以在主体状态变化时提供不同内容，而使用它的属性仍保持一份稳定声明。多个变量组合时，状态不应沿消费链复制成不断增加的属性分支。

# 典型案例

```ts
const color = variable('red', {
  name: 'probe-color', states: { hover: 'pink', active: 'darkred' },
})
const css = compileRules([[[condition('.Probe')], 'color', color]])
expect(css).toContain('color: var(--probe-color);')
expect(css).toContain('--probe-color: red;')
expect(css).toContain('--probe-color: pink;')
expect(css).toContain('--probe-color: darkred;')
```

## 本次基础与组合

`variable({ default: '4px', hover: base => add(base, '2px') }, 'size')`普通4px、悬停6px；当地基础10px时悬停12px。状态回调取得本次声明的有效基础，不是尚未执行的函数对象；0等有效基础不能因真假判断被替换。

每个对象只使用自己的状态。组合表达式读取来源当前CSS值，不把来源JS状态配置复制为自己的状态；来源在当地变化的计算结果见[当地输入响应](派生结果跟随当地输入变化.md)。

# 反例

浏览器中的Probe应普通为红、悬停为粉红、按压为深红；消费属性保持引用该变量，不因组合层数增加而复制成不断增长的状态属性分支。CSS文本检查只能发现缺少引用或状态内容，不能代替浏览器结果。生成声明条数与排列不是契约；当前三项值只是用于识别错误结果。
