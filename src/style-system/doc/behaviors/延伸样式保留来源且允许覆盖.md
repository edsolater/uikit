# 目的

用derive在创建时复用默认内容与状态，派生定义只改变自己负责的部分，不改来源。状态覆盖的显式0必须保留；需要独立CSS实体时给新名。

# 典型案例

```ts
import { compileRules } from '../../css-root'
import { variable } from '../../variable'

const source = variable({ default: 1, hover: 0.75, disabled: 0.5 }, 'source-ratio')
const next = source.derive(source.content, { name: 'next-ratio', states: { disabled: 0 } })
const css = compileRules([[['.Next'], 'opacity', next]])
```

Next常态1、hover0.75、disabled0；source保持disabled0.5。新对象不会自动跟随后续母体JS配置修改。普通variable(source,name)只是引用内容，不等于复用状态定义。

# 反例

把0当缺省、修改来源、丢失hover或把同名其他对象状态注入，都违反目的。
