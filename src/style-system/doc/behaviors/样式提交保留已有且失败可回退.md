# 目的

Style System 更新页面样式时，既有样式不能丢失；新一轮生成或提交失败时，页面应继续使用上次成功的结果。单纯读取编译结果也不应提前改写页面。

# 典型案例

```ts
const style = document.head.appendChild(document.createElement('style'))
style.id = 'css-root'
style.textContent = '.existing { color: red; }'
const good = rule('.Probe', 'width', '12px')
let bad: ReturnType<typeof rule> | undefined
try {
  const compiled = compileCSS()
  expect(compiled).toContain('width: 12px;')
  expect(style.textContent).toBe('.existing { color: red; }')

  cssRoot.mount()
  const committed = style.textContent
  expect(style.sheet!.cssRules[0].cssText).toContain('.existing')
  expect(committed).toContain('width: 12px;')
  style.remove()
  expect(() => cssRoot.mount()).toThrow('缺少样式挂载节点')
  document.head.append(style)

  bad = rule('.Probe', 'color', variable('red', {
    name: 'unknown-color', states: { unknown: 'blue' },
  }))
  expect(() => cssRoot.mount()).toThrow('未知 State Condition')
  expect(style.textContent).toBe(committed)
} finally {
  bad?.remove()
  good.remove()
  style.remove()
}
```

# 反例

若 `compileCSS()` 提前写 DOM、挂载抹掉 `.existing`，或失败时写入部分新 CSS，断言失败。
