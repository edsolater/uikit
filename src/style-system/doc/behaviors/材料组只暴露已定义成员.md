# 目的

一组材料只提供作者明确声明的成员。直接使用可取得默认材料，按成员选择可取得原对象；未知成员不能被临时推算或悄悄退回默认值。

# 典型案例

```ts
const ordinary = variable('red', { name: 'ordinary-color' })
const soft = variable('pink', {
  name: 'soft-color', states: { active: 'purple' },
})
const colors = variableCluster({ default: ordinary, soft })

expect(colors('soft')).toBe(soft)
const css = compileRules([
  [[condition('.Ordinary')], 'color', colors],
  [[condition('.Soft')], 'color', colors('soft')],
])
expect(css).toContain('color: var(--ordinary-color, red);')
expect(css).toContain('--soft-color: purple;')
expect(() => (colors as (name: string) => unknown)('missing')).toThrow('未定义成员')
```

# 反例

若直接消费选了 soft、选择时复制出新对象并丢失状态，或缺失成员退回 default，断言失败。
