一份内容可能依赖属性注册、函数、关键帧或其他Rules。业务使用内容时，这些资源应一起可用；不再使用时应退出。共享资源还需要等待最后一个使用者退出，避免一处撤销破坏另一处。

# 使用内容时提供它所需的资源

最终CSS只包含实际需要的Variable定义和按需资源。仅创建定义不产生输出，不运行未使用的生产函数或onActive。下面将一个CSS引用和提供它所需的规则一起包装：

```ts
const onActive = vi.fn((): Rules => [
  [[':root'], '--probe-size', '10px'],
])
const size = value('var(--probe-size)', { onActive })
expect(onActive).not.toHaveBeenCalled()
const handle = rule('.Probe', 'width', size)
try {
  const css = compileCSS()
  expect(css).toContain('width: var(--probe-size);')
  expect(css).toContain('--probe-size: 10px;')
  handle.remove()
  expect(compileCSS()).toBe('')
} finally { handle.remove() }
```

实际消费提供所需资源；onActive返回的真实Rules和稍后展开内容也可引入依赖。普通资源描述文本不被误当Variable消费；Name和纯CSS字符串不激活同名定义。

同一资源有多个消费者时，撤销一个仍保留其余需求；最后需求退出才释放。内容从A换为B、局部声明被更新、规则撤销或重新编译时，旧独占依赖退出，新依赖完整生效。例如A默认4/hover6且独有资源a，B默认10/hover12且资源b，切换后页面普通10/hover12，无其他需求时a和A独占状态均退出。

不能用上次生成结果替代本次需求，也不能为探测依赖额外执行源函数并混用不同返回。资源生命周期由实际输出与需求验证，不把永久精确回调次数、内部节点或中间变量数作为约定。

# 同名资源按完整定义接管

属性注册或具名函数最终由CSS名称识别。新定义接管同一个资源名时，必须作为一整份定义替换；混入旧字段会产生调用者从未写过的第三份定义。

```ts
const old = variable(undefined, {
  name: 'replacement',
  registration: { syntax: '<length>', inherits: true, initialValue: '7px' },
})
const latest = variable(undefined, {
  name: 'replacement', registration: { syntax: '*', inherits: false },
})
const css = compileRules([
  [['.Old'], 'width', old], [['.New'], 'width', latest],
])
expect(css.match(/@property --replacement/g)).toHaveLength(1)
expect(css).toContain('syntax: "*";')
expect(css).toContain('inherits: false;')
expect(css).not.toContain('initial-value: 7px;')
```

同名CSSFunction也完整替换：旧函数有--old字段，新函数仅result使用`var(--old, 24px)`，结果只保留新函数，不借入旧--old定义。

资源接管与对象按名称关联不同。A/B为不同Variable但注册同名属性时，先消费A、首次消费B、再增加A消费，仍保留完整B注册；仍活跃A的重复消费不能反盖B。A全部消费者退出、之后重新激活A时，A才可再次完整接管。须同时验证A→B→A仍为B，以及A全退出重激活后为A，不能只看单向旧→新替换。

# 属性注册保持CSS描述符含义

需要让浏览器约束自定义属性类型、继承或初始值时，使用registration。它表达浏览器的@property规则，不能被Variable的创建内容替代。

registration明确提供syntax:string、inherits:boolean，可选initialValue:ValueInput，分别输出@property描述符。入口校验前两项类型；注册是否合法继续由浏览器规则决定，不承诺任意注册必定有效。

initialValue独立于Variable创建默认，不由默认推断；省略时不输出initial-value。例如创建默认4、注册`<number>`/inherits:false/initialValue1，在父元素显式声明后，无自身声明的子元素读取应为1；子元素自身声明7则为7，撤销后恢复1。不能因父默认4就改写注册初值，也不能对inherits:false的后代承诺自动继承父值。

注册跟随实际需求退出；调整结果仍保留来源原名注册与资源，不把注册悄悄移为匿名结果名字。[完整加工](完整结果调整与局部修改.md)继续尊重类型、继承和显式初值。
