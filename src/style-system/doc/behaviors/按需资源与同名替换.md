一份样式内容可能依赖属性注册、函数、关键帧或其他规则。使用者应当取得一份可用内容，而不是自己追踪并补齐其资源；退出时，也不能删除其他使用者仍需要的资源。

# 使用带入需求，最后需求退出才释放

```ts
const size = value('var(--probe-size)', {
  onActive: () => [[[':root'], '--probe-size', '10px']],
})
const first = rule('.A', 'width', size)
const second = rule('.B', 'width', size)
```

只创建 size 不输出资源。编译实际使用后，A、B 的宽度引用可取得 10px。撤销 first，B 和资源仍在；撤销 second，独占资源才退出。Name 或纯 CSS 引用字符串不查找同名 Variable，不暗中激活其 JS 定义。

内容从 A 换为 B 时，下一次构建取得 B 的值、state 与资源；A 的独占需求退出，共享需求保留。不能用上次生成结果代替当前需求，或因旧产物仍存在而把它误当作当前消费。

资源归属来自实际内容依赖与定义明确持有的配置，不追踪对象创建历史。adjust 返回的 Variable 和普通 Variable 使用同一规则：其内容依赖来源或 Modification 时，消费结果就保留这些依赖所需资源；仅消费某个 variant 时也按它的真实需求判断。variableFrom 与 mapVariableRules 继承未指定的 registration、onActive 和 compileWaveIndex，显式配置覆盖它们；继承的配置按同一资源生命周期消费，不要求业务补登记或重复执行激活回调。当前可选配置边界见 [接口协议](../当前接口与扩展协议.md#variable-输入命名与可选配置)。

# 同名资源完整接管，不混成第三份定义

CSS 属性注册和具名函数以 CSS 名称识别。新的有效定义接管同名资源时，整份替换，不能把旧字段补进新定义。例如旧注册具有 initial-value:7px，新注册没有该字段，则接管后不能残留 7px。

仍活跃的旧定义增加一个消费者，不等于重新进入并接管资源。A 激活、B 激活接管、A 再增加消费，仍由 B 提供；A 全部退出后重新激活，才可能重新接管。这里约束接管事件，不按最后遍历到哪个消费者决定资源版本。

# 属性注册遵循浏览器含义

registration 表达 CSS 对类型、继承和初始值的约束，不是另一套创建默认值。initialValue 不从 Variable 创建内容推断；省略就不输出该描述符。

例如注册 inherits:false、初始值 1，父声明 4；没有自身声明的子元素取 1，不是 4。子元素明确声明 7 后取 7，撤销后回到 1。完整加工也必须尊重这个边界，不能为了让结果传播擅自改成继承。
