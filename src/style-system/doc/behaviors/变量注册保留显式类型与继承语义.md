# 目的

显式属性注册保留类型、继承与初始值的CSS含义，注册初始值不能冒充Variable默认内容。

# 典型案例

行为伪代码，不能直接运行：创建默认4、注册<number>/inherits:false/initialValue1的变量，在父元素显式声明并挂载；无自身声明的子元素读取自定义属性应为1。再为子元素声明7应读7；撤销子声明应恢复1。独立检查输出@property的显式描述符。

**现役契约**：registration明确提供syntax和inherits，可选initialValue；它们分别输出对应@property描述符。initialValue独立于Variable默认，不从默认自动推断。省略initialValue不擅自补上默认；不合法的浏览器注册由CSS规则决定，不能承诺任意注册一定有效。

例如合法`syntax: '<number>'`、`inherits: false`、`initialValue: 1`的属性，在没有适用自身声明的后代不继承祖先的数值，而采用注册初始值。后代若需要独立默认，应在那里明确建立适用声明；不能承诺它自动继承祖先值。注册不改写Variable创建默认，也不把初始值当作局部变化基础的替代品。

公开registration字段为syntax: string、inherits: boolean、initialValue?: ValueInput，分别对应CSS描述符；现有运行校验要求前两项为相应类型。字段形状及其结果由本篇负责，不需读取外部参考取得条件。同主体相对修改的交叉案例见[相对修改](相对修改保留基础与操作顺序.md)。

清理：撤销父子声明及消费后重编译，最后需求退出时注册资源退出；移除案例元素及案例style。

# 反例

将默认4自动写作注册initial-value而覆盖显式1、省略initialValue时擅自推断，或无自身声明的后代在inherits:false时误读祖先值，均违反目的。
