业务数据需要带着格式和引用关系组成 CSS。Value 保存内容及其解释方式，Expression 组织已有内容；两者让业务不必每次手工重拼单位、比例或依赖，但不因此获得 Variable 的 state 定义能力。

# 换数据不丢解释方式

```ts
const duration = value<number>(200, { toCSSString: ms => `${ms}ms` })
const slower = duration.withContent(400)
```

duration 输出 200ms，slower 输出 400ms，原内容仍是 200。新包装保留格式和约定的依赖、资源能力；依赖若由内容计算，就以新内容求取。换数据不能意外改写原包装，也不能丢掉所需资源。

数组与列表组合保持明确的逗号或空格含义，空项不占分隔位置，0 等合法值保留。组合输出读取已经取得的子项结果，不为格式化再次运行生产函数。

# 组合保留组成部分的 CSS 含义

```ts
colorMix(['black', 0.5], 'white')
multiply('12px', 2)
fontValue({ style: 'italic', size: '16px', lineHeight: 1.5, family: 'system-ui' })
```

分别表达黑色占 50% 的混色、24px 的计算宽度和 `italic 16px/1.5 system-ui` 字体。混色比例、单位和字体斜杠不能被通用输出丢掉。CSS 函数定义可带参数，动画内容可依赖关键帧；调用或组合时同时保留依赖，资源进入与退出由 [按需资源与同名替换.md](按需资源与同名替换.md) 决定。

Expression 保留实际引用，不复制来源的 JS states，不自动产生 state 交集。若表达式成为 Variable 的根据地内容，其求值位置由该根据地决定；普通内容包装不能绕过 [CSS作用域与层叠.md](CSS作用域与层叠.md)。

# 只为实际需要的内容求值

创建材料和登记使用不提前执行业务生产函数；构建消费时才求取需要的内容。根据地已有有效声明替代创建内容时，不为取得无用默认内容额外执行函数；显式 undefined 也不触发回填。

一次消费中不能为探测依赖额外运行源函数，再把不同返回值混用。这里保护的是同一次结果的一致性，不给所有回调规定永久精确调用次数。求值失败明确报错，不能把函数源码当 CSS 或吞掉异常。

共享不是递归：同一 Value 在混色两端出现应能正常完成；Value 最终又依赖自己，或 Rules 包含自身，则明确失败，不无界增长或交付部分 CSS。合法有限组合不应因为共享被误判为循环；这不承诺分析任意 CSS 自定义属性环。
