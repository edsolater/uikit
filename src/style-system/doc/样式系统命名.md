# Style System 命名

名字先给出稳定服务对象，再在后面追加成员、档位或配方后缀。例如 `dangerColorStrong`、`controlSizeSmall`、`surfaceColorInteractive`；CSS 名字保持相同顺序：`danger-color-strong`、`control-size-small`、`surface-color-interactive`。

## 对象命名

| 对象 | 示例 | 含义 |
| --- | --- | --- |
| JSSKey | $backgroundColor、$opacity | 原生 CSS 声明目标 |
| Variable | surfaceColor、durationFast | 有稳定服务对象、可承载状态的 Atom |
| Mixin | color、boundary、clickable | 完整效果，直接使用效果名称 |
| State Condition | hover、active、focusVisible | 主体自身状态 |

`surfaceColor`、`controlSize`、`dangerColor` 是稳定身份；`bare`、`small`、`strong`、`0` 是该身份下的成员、档位或配方选择，因此放在后面。描述性部分内部的 `color`、`size`、`width` 仍留在稳定身份末尾，但整个标识符不要求以它们结尾。

多个独立颜色可按各自用途命名，状态与用途怎样区分参照[states与条件选择.md](behaviors/states与条件选择.md)。例如lineColor(base)可以用基础名称拼接线条用途；具体字符串化结果由[Variable的创建与复用.md](behaviors/Variable的创建与复用.md)负责。

名称必须对应稳定服务对象。当前 24px Atom 没有独立 Heading 消费者，因此使用 `textSizeExtraExtraLarge`，不以 `headingSize` 假造服务对象。反过来，若未来内容只服务文章标题，`headingSize` 就是稳定对象，不必改成 `textSizeHeading`。

需要状态的内容如何选择Value或Variable，见[states与条件选择.md](behaviors/states与条件选择.md)。本页的命名建议不要求既有Value一律改名，也不要求所有名字追加字面上的Unit或CSS单位。

## 通用用途与组件用途的名字

例如buttonSurfaceColor、buttonContentColor指向Button用途；buttonColor保存变体定义，buttonColor.variant('line')选择其中的line变体，paperColor、inkColor、brandColor指向基础材料，lineStrength表达线条强度。这些例子用于选择稳定服务对象的名字，不规定对象必须从哪里取得内容；全局来源与组件关系见[共享主题与组件颜色控制.md](behaviors/共享主题与组件颜色控制.md)，实际接入见[架构](../architecture.md#button-接入)。
