# Style System 命名

名字先给出稳定服务对象，再在后面追加成员、档位或配方后缀。例如 `dangerColorStrong`、`controlSizeSmall`、`surfaceColorInteractive`；CSS 名字保持相同顺序：`danger-color-strong`、`control-size-small`、`surface-color-interactive`。

## 对象命名

| 对象 | 示例 | 含义 |
| --- | --- | --- |
| JSSKey | $backgroundColor、$opacity | 原生 CSS 声明目标 |
| Variable | surfaceColor、durationFast | 有稳定服务对象、可承载状态的 Atom |
| Mixin | color、boundary、clickable | 完整效果 |
| State Condition | hover、active、focusVisible | 主体自身状态 |

`surfaceColor`、`controlSize`、`dangerColor` 是稳定身份；`bare`、`small`、`strong`、`0` 是该身份下的成员、档位或配方选择，因此放在后面。描述性部分内部的 `color`、`size`、`width` 仍留在稳定身份末尾，但整个标识符不要求以它们结尾。

多个独立颜色直接使用各自的用途名；hover、active是Variable状态，不另建成员身份。普通转换函数如lineColor(base)返回以基础名组合的具体Variable。VariableName字符串化是逻辑名，CSS地址仍由名称正规化生成。

名称必须对应稳定服务对象。当前 24px Atom 没有独立 Heading 消费者，因此使用 `textSizeExtraExtraLarge`，不以 `headingSize` 假造服务对象。反过来，若未来内容只服务文章标题，`headingSize` 就是稳定对象，不必改成 `textSizeHeading`。

Value 只表达稳定内容；不能为承载状态而建立智能 Value。命名规则不要求把既有稳定 Value 一律改名，也不要求所有名字追加字面上的 Unit 或 CSS 单位。

## 通用与组件归属

组件拥有自己的具体颜色定义，例如buttonSurfaceColor、buttonContentColor、buttonLineColor。paperColor、inkColor、brandColor是可控制的基础材料；lineColor是转换函数，lineStrength是共享强度实体，不经global中转。
