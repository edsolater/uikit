# Variable：定义、复用与显式变化

Variable 是一个有名称、内容和可选状态的 CSS 实体。需要共享控制点或复用交互反馈时创建它；固定的一次性内容直接交给 Mixin。完整组件用法见[按钮教程](从按钮需求组合样式.md)。

## 先决定定义存在在哪里

创建时的 `address` 是根据地。省略时在 root；消费会保障那里有声明，已有声明则保留。states 只随根据地展开；非根据地显式赋新值仅改变当地CSS值，不发布整套states。

```ts
import { key, mapVariableRules, multiply, rules, variable, variableFrom } from '@edsolater/uikit/style-system'

const size = variable('4px', {
  name: 'example-size',
  address: '.Button',
  states: { hover: base => multiply(base, 2), active: '12px' },
})
rules('.Button', [[key('width'), size]])
```

Button 普通宽4px，悬停8px，按下12px。业务没有补 `declare(size)`。如果省略 address，状态响应的是根元素，不能用它代替 Button 自身反馈。地址接受现有 Condition、路径字符串或路径数组；嵌套规则与地址应使用相同的路径材料。

## 用普通函数保存转换规则

转换函数是有意义的半成品和骨骼：它先描述“怎样从表面得到线条”，调用后才创建可以声明和控制的 CSS 实体。函数自己不需要一个 CSS 身份。

```ts
import { colorMix, key, lineColor, rules, variable } from '@edsolater/uikit/style-system'

const surface = variable('red', {
  name: 'example-surface', address: '.Card',
  states: { hover: 'blue' },
  variants: { emphasized: 'green' },
})
const line = lineColor(surface)
rules('.Card', [[key('border-color'), line]])
```

`lineColor(surface)` 沿用 surface 的根据地、声明等级和注册配置，将默认、状态与用途各自的最终颜色混入共享 `lineStrength` 指定的比例；来源本身不变。这里 Card 普通是18%的红色线条，悬停是18%的蓝色线条；`line.variant('emphasized')` 普通为18%的绿色线条，悬停仍为18%的蓝色线条。固定颜色、状态规则及用途自带状态都先得到自己的结果，再转换一次。

surface 和 line 都在 Card 根据地按需声明，业务不必再用 `variableFrom` 补地址。改变 Card 的 surface 或线条强度会动态更新线条；如果 surface 的根据地在根，line 也在根，只在 Card 下另设同名 surface 不会让继承的 line 重新计算。这是[CSS作用域与层叠.md](behaviors/CSS作用域与层叠.md)。需要不同局部公式时，应在当地创建基础；其他整份结果的变化见下面的 adjust 或 modify。

## 用 variableFrom 复用复杂状态和变体

普通函数复用转换算法；`variableFrom` 复用已有定义。新内容、状态或地址差异只写一次，业务不必知道来源有多少状态。

```ts
const wider = variableFrom(size, '7px', {
  name: 'example-wide-size', address: '.WideButton',
})
rules('.WideButton', [[key('width'), wider]])
```

WideButton 普通7px，悬停14px，按下仍为固定12px；原 Button 不变。规则和固定值都原样继承，没有额外联动。未指定新地址时沿用来源根据地；未指定新名字时沿用来源名称，所以独立对象仍可能参与同名 CSS 层叠。

```ts
const renamed = variableFrom(size, '6px', name => `large-${name}`)
const stateOnly = variableFrom(size, size.content, {
  name: 'example-fixed-hover', states: { hover: '20px' }, priority: 0,
})
```

名称仍为可字符串化的 VariableName 对象；它只提供 CSS 标识，不查找或激活同名 JS 定义。继承发生在创建时，来源之后的 JS 配置变化不回写结果。完整边界见[Variable的创建与复用.md](behaviors/Variable的创建与复用.md)。

## 将各项最终取值统一映射

替换基础会保留原规则；映射则先取得默认、state、variant 各自的最终结果，再逐项加工：

```ts
const doubled = mapVariableRules(size, result => multiply(result, 2), 'example-doubled-size')
```

size 的普通、hover、active 分别是 4px、8px、12px，因此 doubled 为 8px、16px、24px。来源不变。省略第三项时沿用来源名称；其他未指定配置同样继承来源，显式配置覆盖对应项。映射结果仍是普通 Variable，再替换其基础时不重放旧映射。

## 用 variant 选择用途

```ts
const color = variable('red', {
  name: 'example-color', address: '.Swatch',
  states: { hover: 'blue' },
  variants: { surface: base => colorMix([base, 0.2], 'transparent'), line: 'green' },
})
rules('.Swatch', [[key('border-color'), color.variant('line')]])
```

普通边线绿色、悬停蓝色。variant 返回 Variable，继承状态及根据地，消掉来源的这一层 variants；使用处直接选择，不必导出每个成员。固定 hover 不会因普通值变绿而变成另一条规则。结果也可以作为 variableFrom 的来源。

## 同一变化用于全部结果

```ts
import { adjust, color as paint, modification, modify } from '@edsolater/uikit/style-system'

const halfOpacity = modification({ type: 'color', detail: { alpha: 0.5 } })
const faded = adjust(color, halfOpacity)
rules('.Swatch', [paint({ background: faded })])
rules(['.Swatch', '&.Muted'], [modify(color, halfOpacity)])
```

`adjust` 创建新 Variable，沿用来源根据地：faded 普通半透明红、hover 半透明蓝，`faded.variant('line')` 为半透明绿，来源不变。`modify` 返回条件声明：这里只在 Muted Swatch 内让 color 及选用的变体结果半透明，其他范围保持原样。两者都先取得所选结果，再加工一次；不是只改默认，也不是反复加工基础。

数值修改可用 `{ type: 'expression', detail: current => multiply(current, 2) }`。多个步骤按书写顺序累计；共享 `id` 表示同一步的条件候选。完整例子与撤销效果见[adjust与modify.md](behaviors/adjust与modify.md)。

## 显式赋值与使用入口

`declare(target, newValue)` 表达真实的新值；无值 declare 只保留为逃生舱，普通业务不使用，也不重传创建内容补基础。多个独立目标需要同条件换值时并列声明，没有隐式组成员配对。

业务用 `compileCSS()` 读取，或用 `cssRoot.mount()` 提交；动态规则保存句柄以便替换和撤销。选择定义、地址与加工方法即可，无需阅读内部编译结构。API 形状见[参考](样式系统API参考.md)，结果边界见[__spec.md](behaviors/__spec.md)。
