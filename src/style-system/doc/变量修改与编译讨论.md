# Variable 修改讨论的当前结论

Variable 的稳定目的、使用形式与能力边界已归入 [变量定义与消费](变量定义与消费.md)，包括局部 declare、相对 modify、状态先给基础值、任意 payload 和 CSS 运行时条件组合。

当前实现由 Variable 自身的 `compile` 方法按需使用 AST 能力。具体输入引用、默认传递、局部重连与生命周期的修改途径见 [Plan](../../../docs/plans/StyleSystem变量修改与AST改写.md)，实际修改原因、代价和验证证据见 [实施详情](../../../docs/plans/StyleSystem变量修改与AST改写_实施详情.md)。

此前讨论中的独立 Rewriter、操作中转和整组表达式重建已退出；本文不再保留第二套现役规则。
