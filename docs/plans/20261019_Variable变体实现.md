# 目标与采用边界

本计划将 Variable 的通用变体接入创建、derive 和普通消费链，并用真实 Button 验证业务简化。Behavior、测试与生产实现一并更新；实现已经落盘，验收结果见末节。

用户最新裁决：state 与 variant 都允许规则或固定值，derive 原样继承定义。规则在新基础上求值，固定值保持原值；不增加父子联动机制。所有 Variable 都有 derive，variant 结果保留状态并消掉父层 variants。具体用途与教程由[Behavior](../../src/style-system/doc/behaviors/变体保留配方并使用独立基础.md)负责。

# 实施顺序与结果

1. **先补失败测试。** 在最初命名为 slot 时的行为红测上加入规则/固定值继承、0 值、普通 Variable 派生及变体结果再派生。旧实现为 1 项通过、6 项因缺少选择入口失败。真实 Button 新增“危险语气只覆盖一个 tone 输入”案例，旧业务代码失败。
2. **接入真实类型。** VariableOptions.variants 接受按名称定义的规则或 ValueInput；每个 Variable 暴露 variant。测试移除局部候选接口与类型逃逸。
3. **复用原样继承。** parser 将来源与当前 variants 按名称合并，显式同名项覆盖，其他保留。状态继续沿用原有逻辑，不变换规则、不为固定值自动生成公式。
4. **选择单层用途。** variant 检查名称，规则接收默认表达式，固定值直接保留；调用 derive 生成新名称与状态定义，然后移除结果的父层 variants。结果仍是完整 Variable，沿用派生等级；未知名称抛出错误。可调用 JSSContent 依其内容协议保留，不被误执行成变体规则。
5. **简化 Button。** buttonColorInput 作为实际输入；用途定义的默认表达式显式引用它，soft/strong/line 与固定内容色由 variant 取得。危险条件从 5 个颜色声明缩为 1 个 tone 声明。soft/strong 透明度通过 buttonOpacity.derive 复用 disabled，不重复列状态。
6. **验证与同步。** 新增行为先由 RED 转 GREEN，再跑单元/浏览器回归、类型、构建与实际 dist 消费；同步教程、API 参考与现役架构，保留可观察验收证据。

# 业务改动的意义

过去危险条件既要选择 badColor，还要重复定义柔和色、线色、实色及内容色。现在用途在定义端集中一次，分类只选择底色。变体名称使用 soft、strong、line、content，CSS 地址对应 button-color-soft 等名称；显式声明 buttonColor.variant('line') 仍只覆盖所选部件。

buttonColor 是普通 Variable，其默认表达式明确引用 buttonColorInput。变体表达式因此自然保留这个真实输入，现有声明/依赖链负责区域响应；不是 variant 根据血缘自动关联母体。直接转换 literal 的变体仍保持 literal 语义。

# 通用命名与本轮改良

配置统一为 variants，选择方法为 variant(name)，公开类型为 VariableVariantRule；源码、Button、测试文件名、Behavior、API 参考与链接一次迁移，不保留旧入口转发。语义继续沿用已经确定的定义继承，不新增联动。教程补充尺寸示例，使通用能力不被误解成颜色或部件位置专用；未知变体测试按现行抛错行为收紧，并覆盖结果再派生后仍不恢复来源变体。

# Button 使用端收口

成员定义留在 buttonColor.variants，使用端直接调用 variant，不再导出 buttonSoftColor 等成员别名。原 buttonToneColor 输入更名为 buttonColorInput，明确区分可声明的局部输入与保存变体规则的主体，不增加母体隐式联动。

无值 declare 从10条减至4条。删除全部声明的试验使 modify 找不到局部基础；只保留 strength 后还丢失危险焦点色、局部文本改色与画布 hover。最终保留 input、strong、canvas、strength 的局部定义，让公式/状态在每个 Button 内求值；其他默认由自动机制补足。声明是作用域选择而不仅是默认值补齐，是否能删除由效果和职责决定。

本轮仅收口 Button 的业务表达和声明作用域，不改变重复选择身份约定。公开入口、现役文档及测试改为 buttonColor / buttonColorInput，历史 Plan 示例保持原有上下文。最新回归为439项单元、184项浏览器测试及类型/构建/dist消费通过，证据位于 agents/run/20261019-button-color/。

# 本轮边界

不实现嵌套变体，不承诺同变体重复读取的对象相等性。未知变体明确拒绝，variant 使用普通 derive 的优先等级，不增加独立等级计算。变体定义继承不等于运行时观察母体配置；更改来源 JS 定义不会回写已经创建的派生体。
