# 替代的旧方案

| 退出方案                                             | 本轮采用的职责                                                                                                 |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 独立根默认兜底系统，与自动 declare 分开维护          | 创建时确定根据地，消费时只保障该地址有声明；root 只是缺省地址，不是另一条默认值路径。                          |
| 根据局部输入声明自动重声明整条组合公式               | 遵循现有 CSS 求值和继承，局部同名绑定不使祖先公式重新绑定；局部修改显式使用 modify。                           |
| 新增 Variable 领域 declare-tree.ts，提供最近声明查询 | 不建该文件或平行声明树；复用 AST 指定地址的 has/search 能力。                                                  |
| source.derive(...) 或 changeTo(...)                  | variableFrom(source, value, nameOrOptions)，后两项与 variable 的创建材料位置一致，支持继承名称及来源名称映射。 |
| adjust 仅构造 source 与配方引用的单一结果            | 升级为完整结果加工，保留来源与配方当前 CSS 引用控制，不退化为创建值快照。                                      |
| modify 只改变某一基础，状态或变体可能绕开它          | 在匹配范围内对目标各结果都应用修改，保留步骤与退出效果。                                                       |

本计划覆盖旧[变体 Plan](20261019_Variable变体实现.md)与[局部重声明 Plan](20261019_变量局部重声明与动态依赖.md)中上述冲突方案。旧文只保留历史记录；VariableName 对象及字符串化、具体对象携带定义、priority 显式 0、注册语义、状态顺序和资源生命周期等未被取代的契约继续保留。CSS 名称不恢复成 JS 定义关联或激活身份。

# 已确定的接口细节

- 配置字段为 `address`，类型复用 `ConditionInput`（排除 undefined）；未指定时使用根元素。默认输出 `:where(:root)`，避免创建内容压过显式根主题。
- variableFrom 与 variant、adjust 沿用来源根据地；variableFrom 可在 options.address 显式换地址。基础 variable 省略地址仍为 root。
- states 随根据地声明。组件需要自身状态模板时指定组件地址；也可在明确的 hover/active 条件 rules 中显式 modify，不向每个消费点展开。
- AST 的 findDeclaration 负责指定地址的有效声明选择，复用同名/路径查询及优先协议；完整单层 :root 与 :where(:root) 识别为同一物理根，先尊重两者已知的原生特异度差异。显式 undefined 也算已有声明，不补回创建内容。不新增通用选择器解析器。
- adjust 保持两参，不新增命名/地址第三参；结果独立命名并沿用来源地址。variableFrom 的 registration、onActive、compileWaveIndex 仍需显式提供；adjust 保留加工来源已持有的资源生命周期。

# 实行说明

Variable 仍拥有定义，AST 仍拥有节点查询与源序，文件定位保持。`variable/dependency.ts` 整个删除，独立根兜底、消费点状态投影、局部输入观察及公式搬运图一起退出；不以改名文件保留平行路径。`variable/declare.ts` 统一根据地声明和状态发布，`ASTController.findDeclaration` 统一有效声明选择，没有 Variable 私有声明树。

创建入口改为 variableFrom，旧 derive 方法和类型退出，无兼容转发。states/variants 规则及固定值创建时继承，名称对象仍只负责 CSS 标识。adjust 保留来源与配方当前CSS引用，覆盖完整定义的最终选择结果；modify 复用按步骤、条件候选和撤销的原有能力，将加工覆盖到实际使用的变体。显式变体选择记录只表达这个完整加工关系，不追踪任意内容依赖。

Button 删除四条无值补偿声明。来源、画布、强度、阴影、透明度和 clickable 内部反馈明确指定组件或外观地址；状态模板通过 variableFrom 复用。根主题来源、普通/危险、各外观、焦点与禁用用途保留。祖先局部同名输入不再隐式搬运颜色公式，区域定制直接选择组件控制点。

测试从新目的出发：保留名称、资源、编译、优先、步骤顺序和实际颜色验证；旧逐消费状态与当地投影案例改为显式地址或独立当地定义；只锁旧观察图及扫描次数的实验删除。后写显式新值仍覆盖前面的 modify，先写新值再 modify 则加工新值，不能通过改期望掩盖源序变化。
