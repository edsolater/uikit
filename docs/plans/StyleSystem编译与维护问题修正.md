- **顺序与前置：** 在扫描优化前先固定存活合同，使后续结构改动有行为基准。
- **最小验收：** 通过 Controller 建立 A、B、P，依上述顺序操作，断言对已撤销 B 的 depend 明确失败；移除 A 后 P 被清理且 onRemove 只执行一次。对 `remove(B, { from: 'output' })` 则允许 depend，移除 A 后 P 仍存活，真正撤销 B 后才清理。
