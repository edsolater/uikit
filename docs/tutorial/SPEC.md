# Tutorial

## 目录职责

- 本目录存放当前仓库对外指导文档。
- 本目录强调“什么时候这样用、为什么这样用、不要什么时候这样用”。
- 本目录说明稳定 API、推荐写法、边界判断和不推荐写法。
- 本目录不写具体改造步骤；修改步骤应放进 `docs/plans`。
- 本目录不写组件的稳定定义；这类内容应放进 `docs/guide`。
- 本目录里的文档默认面向组件库使用者和维护者共同阅读。
